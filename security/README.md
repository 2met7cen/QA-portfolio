# Security findings

В ходе тестирования API обнаружены уязвимости управления доступом.

## IDOR: доступ к чужим заказам

- **Эндпоинт:** `GET /api/orders/{id}`
- **Приоритет:** Critical
- **Суть:** авторизованный продавец может получить данные заказа,
  который ему не принадлежит. Сервер не проверяет владельца ресурса.
- **Ожидалось:** 403 / 404
- **Фактически:** 200 с данными чужого заказа

## Удаление проданного питомца

- **Эндпоинт:** `DELETE /api/pets/{id}`
- **Приоритет:** Critical
- **Суть:** можно удалить питомца, по которому уже есть оформленный заказ.
- **Ожидалось:** 400 / 409
- **Фактически:** 204
