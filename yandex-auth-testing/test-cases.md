# Тест-кейсы: авторизация через Яндекс ID на ya.ru

**Объект тестирования:** форма авторизации Яндекс ID на странице ya.ru (мобильная версия).

**Среда тестирования:**
- Эмуляция мобильного устройства в Chrome DevTools.
- Устройство: Pixel 7.
- Браузер: Google Chrome.

**Область тестирования:**

*Входит:*
- переход на форму авторизации с главной ya.ru;
- вход по номеру телефона;
- вход по логину и паролю;
- валидация полей;
- навигация внутри формы авторизации;
- атрибуты полей ввода.

*Не входит:*
- регистрация нового аккаунта;
- вход через сторонние сервисы (VK, Google, Mail.ru);
- двухфакторная аутентификация;
- вход по биометрии и QR-коду;
- восстановление пароля;
- выход из аккаунта;
- поведение при срабатывании капчи.

---

## TC-01. Переход на форму авторизации

- **Приоритет:** High
- **Предусловие:** пользователь не авторизован, открыта главная ya.ru (мобильная версия).
- **Шаги:**
  1. Тапнуть по кнопке «Войти» в правом верхнем углу.
- **Ожидаемый результат:** открывается форма авторизации Яндекс ID, поле ввода телефона активно, отображаются кнопки «По лицу или отпечатку» и «Ещё».

---

## TC-02. Вход по валидному номеру телефона

- **Приоритет:** Critical
- **Предусловие:** аккаунт существует и привязан к номеру телефона.
- **Шаги:**
  1. Открыть форму авторизации.
  2. Ввести валидный номер телефона.
  3. Нажать «Войти».
  4. Ввести код из СМС.
- **Ожидаемый результат:** пользователь авторизован, происходит редирект на ya.ru, в правом верхнем углу отображается аватар профиля.

---

## TC-03. Атрибуты полей ввода

- **Приоритет:** Medium
- **Предусловие:** открыта форма авторизации по телефону.
- **Шаги:**
  1. Проверить атрибуты поля телефона.
  2. Перейти к форме ввода логина через «Ещё» → «Войти по логину», проверить атрибуты поля логина.
  3. Ввести логин, перейти к форме пароля, проверить атрибуты поля пароля.
- **Ожидаемый результат:**
  - поле телефона: `type="tel"`, `inputmode="tel"`, `autocomplete="off"`;
  - поле логина: `type="text"`, `autocomplete="username"`;
  - поле пароля: `type="password"`.

---

## TC-04. Переход к форме логина через меню «Ещё»

- **Приоритет:** High
- **Предусловие:** пользователь не авторизован, открыта форма авторизации по телефону.
- **Шаги:**
  1. Нажать кнопку «Ещё».
  2. Выбрать пункт «Войти по логину».
- **Ожидаемый результат:** открывается форма ввода логина, заголовок меняется на «Введите логин», поле «Логин или email» активно, отображается кнопка «Войти».

---

## TC-05. Переход к форме ввода пароля после ввода логина

- **Приоритет:** High
- **Предусловие:** аккаунт существует, открыта форма ввода логина.
- **Шаги:**
  1. Ввести валидный логин.
  2. Нажать «Войти».
- **Ожидаемый результат:** открывается форма ввода пароля, заголовок меняется на «Введите пароль», поле пароля активно, отображается кнопка «Далее» (неактивна) и ссылка «Не помню пароль».

---

## TC-06. Успешный вход по логину и паролю

- **Приоритет:** Critical
- **Предусловие:** аккаунт существует, есть логин и пароль.
- **Шаги:**
  1. Открыть форму ввода пароля.
  2. Ввести валидный пароль.
  3. Нажать «Далее».
- **Ожидаемый результат:** пользователь авторизован, происходит редирект на ya.ru, в правом верхнем углу отображается аватар профиля.

---

## TC-07. Вход с неверным паролем

- **Приоритет:** High
- **Предусловие:** аккаунт существует, есть логин.
- **Шаги:**
  1. Открыть форму ввода пароля.
  2. Ввести неверный пароль.
  3. Нажать «Далее».
- **Ожидаемый результат:** отображается сообщение об ошибке «Неверный пароль», вход не выполнен, поле пароля доступно для повторного ввода.

---

## TC-08. Вход с несуществующим логином

- **Приоритет:** High
- **Предусловие:** аккаунт с указанным логином не существует.
- **Шаги:**
  1. Открыть форму ввода логина.
  2. Ввести несуществующий логин.
  3. Нажать «Войти».
- **Ожидаемый результат:** отображается сообщение об ошибке «Нет аккаунта с таким логином», вход не выполнен.

---

## TC-09. Вход с пустыми полями

- **Приоритет:** Medium
- **Предусловие:** аккаунт существует, открыта форма ввода логина.
- **Шаги:**
  1. Оставить поле логина пустым.
  2. Нажать «Войти».
- **Ожидаемый результат:** кнопка «Войти» неактивна, либо отображается сообщение о необходимости заполнить поле.

---

## TC-10. Валидация формата телефона

- **Приоритет:** Medium
- **Предусловие:** открыта форма авторизации по телефону.
- **Шаги:**
  1. Ввести неполный номер телефона.
  2. Наблюдать за состоянием кнопки «Войти».
- **Ожидаемый результат:** кнопка «Войти» неактивна, пока номер не введён полностью.
