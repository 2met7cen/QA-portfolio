# yandex-auth-testing

Учебный проект: тест-кейсы для формы авторизации Яндекс ID на ya.ru (мобильная версия).

**Цель:** отработать навык написания тест-кейсов для мобильного веб-приложения.

## Что внутри

- [`test-cases.md`](./test-cases.md) — 10 тест-кейсов с приоритетами, предусловиями, шагами и ожидаемыми результатами.

## Область тестирования

**Входит:**
- переход на форму авторизации;
- вход по номеру телефона;
- вход по логину и паролю;
- валидация полей;
- навигация внутри формы;
- атрибуты полей ввода.

**Не входит:**
- регистрация;
- вход через сторонние сервисы;
- двухфакторная аутентификация;
- биометрия и QR-код;
- восстановление пароля;
- выход из аккаунта;
- капча.

## Среда

- Эмуляция мобильного устройства в Chrome DevTools.
- Устройство: Pixel 7.
- Браузер: Google Chrome.
