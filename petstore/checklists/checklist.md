# Чек-лист: ЗооМаркет API

## Регистрация и авторизация

- [ ] Регистрация с валидными данными — Critical
- [ ] Регистрация с уже существующим логином — ошибка — Critical
- [ ] Вход с валидными данными — получен токен — Critical
- [ ] Вход с невалидным паролем — ошибка — Critical
- [ ] Доступ к защищённым эндпоинтам без токена — 401 — Critical
- [ ] После логина продавец видит только свои данные — High

## Каталог животных

- [ ] `GET /api/pets` — список отображается — Critical
- [ ] По умолчанию 20 записей (или 5) — High
- [ ] Пагинация: переключение страниц — High
- [ ] Пагинация: выбор лимита (5, 10, 20, 100) — Medium
- [ ] `POST /api/pets` — создание с валидными данными — Critical
- [ ] `POST /api/pets` — невалидные данные (пустое имя, отрицательная цена) — ошибка — High
- [ ] `PUT /api/pets/:id` — обновление работает — Critical
- [ ] `DELETE /api/pets/:id` — удаление работает — Critical
- [ ] Поиск по названию работает — High
- [ ] Фильтрация по категории и статусу работает — High
- [ ] Сортировка: новые записи сверху — Medium

## Заказы (продажи)

- [ ] `POST /api/orders` — оформление заказа (валидные данные) — Critical
- [ ] `POST /api/orders` — на уже проданное животное — ошибка — Critical
- [ ] `POST /api/orders` — невалидные данные (пустой покупатель) — ошибка — High
- [ ] `PUT /api/orders/:id/status` — смена статуса (approved / delivered / cancelled) — High
- [ ] `DELETE /api/orders/:id` — удаление заказа — Medium

## Ошибки и UX

- [ ] При попытке без прав — 403 — High
- [ ] При невалидном JSON — 400 с понятным сообщением — High
- [ ] Ошибки на UI выводятся понятным языком — High
- [ ] 404 — сообщение, а не пустой экран — Medium

## Производительность и UI

- [ ] Страницы загружаются < 3 сек — Medium
- [ ] Интерфейс не дёргается — Low
